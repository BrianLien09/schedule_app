# 打工月曆詳細列表箭頭與間距設計規格

## 目標
- 「本月詳細列表」右側顯示 chevron 指示收合狀態。
- 收合時 chevron 向右，展開時向下。
- 標題列與卡片區間距增加 8px。

## 範圍
- 僅調整打工月曆頁面樣式與標題列呈現。
- 不改變收合邏輯或月曆互動行為。

## 版面與互動
- chevron 與「展開/收合」文字同步切換。
- chevron 置於右側，與提示文案同列排列。

## 樣式指引
- chevron 使用小尺寸，低對比但可辨識。
- 間距增加 8px，避免卡片過於貼近標題列。

## 驗收條件
- 收合時顯示向右 chevron；展開時顯示向下 chevron。
- 標題列與卡片區間距比現有增加 8px。

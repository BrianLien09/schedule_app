# 薪資計算自訂班別與自動套用設計規格

## 目標
- 支援在薪資計算中建立可重用的「班別模板」。
- 依班別的星期規則，自動帶入該日薪資記錄的開始/結束時間、工時、時薪。
- 當同一天有多個班別時，提供可控的優先順序。

## 範圍
### 包含
- 新增班別模板資料模型與 Firestore 存放路徑。
- 薪資計算頁新增班別管理 UI。
- 薪資計算頁「空白新增」與「打工月曆匯入」的自動套用規則。

### 不包含
- 影響打工月曆頁既有班次模板（SHIFT_TEMPLATES）的改造。
- 薪資計算以外頁面的 UI 調整。

## 資料模型
### Firestore 路徑
- `/shared/data/shiftTemplates`

### ShiftTemplate
```ts
interface ShiftTemplate {
  id: string;
  name: string;
  weekday: 0 | 1 | 2 | 3 | 4 | 5 | 6; // 0=日, 6=六
  startTime: string; // "HH:mm"
  endTime: string;   // "HH:mm"
  hourlyRate: number;
  isDefault: boolean;
  createdAt: number;
}
```

> 設計原因：
> - `weekday` 與 `isDefault` 提供清楚的優先規則，不必在每次套用時詢問使用者。
> - `createdAt` 讓「非預設」情境仍有穩定排序，避免結果不一致。

## UI 與互動流程
### 班別管理
- 位置：薪資計算頁新增「班別管理」區塊。
- 功能：新增 / 編輯 / 刪除班別模板。
- 欄位：班別名稱、星期幾、開始/結束時間、時薪、預設班別（checkbox）。
- 同一星期可建立多個班別，僅允許一個 `isDefault=true`。

### 自動套用（空白新增）
- 使用者選日期後：
  - 依該日期的星期尋找班別模板。
  - 若找到班別，預填開始/結束時間與時薪，並據此計算工時。
  - 使用者可自行修改預填欄位。

### 自動套用（打工月曆匯入）
- 每筆匯入時：
  - 依班表日期星期尋找班別模板。
  - 若找到班別，覆蓋 `startTime/endTime/hourlyRate`，並重新計算工時與應得薪資。
  - 若沒有班別，沿用原班表時間。

## 優先順序規則
1) 若該星期有 `isDefault=true` 的班別，優先使用。
2) 否則依 `createdAt` 由新到舊挑選第一個。

> 設計原因：
> - 預設班別讓使用者有明確的控制點，避免自動套用結果不穩定。
> - 以建立時間作為後備排序，降低重複詢問與歧義。

## 錯誤處理與邊界條件
- 無班別符合時：不做自動套用。
- 若結束時間早於開始時間：維持現有驗證規則（不新增特殊行為）。
- 班別資料缺失：不套用並在 UI 顯示錯誤提示（沿用現有表單提示樣式）。

## 資料流與依賴
- `useScheduleData` 維持原本使用，不變更打工班表資料。
- 新增 `useShiftTemplates`（或擴充現有 hook）用於讀寫 `shiftTemplates`。
- `SalaryCalculator` 於新增/匯入時查詢班別模板並套用。

## 測試與驗證
- 手動測試：
  - 新增班別模板（含預設）。
  - 在薪資計算頁空白新增，確認自動預填與可覆寫。
  - 從打工月曆匯入，確認自動套用與薪資重新計算。
  - 同星期多班別時，確認優先順序。

# 打工月曆提示區「標題列右側同一行」設計規格

## 目標
- 提示區移到「本月詳細列表」標題列右側，同一行顯示。
- 手機與桌機皆維持同一行，透過縮小字級與內距控制寬度。
- 不影響月曆互動與詳細列表收合行為。

## 範圍
- 僅調整打工月曆頁面排版與樣式。
- 提示文案縮短為「拖曳複製 / Ctrl多選 / 點擊新增」。

## 版面與行為
- 在詳細列表標題列加入右側提示容器，與標題同一行。
- 提示容器使用 `white-space: nowrap`，避免換行。
- 原本位於月曆上方的提示區塊移除，避免重複。

## 樣式指引
- 提示文字使用較低飽和度與小字級，不搶主內容焦點。
- 手機縮小字級與內距，保持單行可讀性。
- 保持現有玻璃擬態與色系一致。

## 驗收條件
- 桌機與手機皆在「本月詳細列表」標題列右側看到同一行提示。
- 月曆互動與詳細列表收合功能不受影響。
- 原本提示區塊不再顯示。

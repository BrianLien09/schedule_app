# 日期顯示週幾設計規格

## 目標
- 在「新增工作紀錄」與「編輯工作紀錄」的日期欄位右側顯示週幾。
- 顯示格式為 `週一`、`週二`。

## 範圍
### 包含
- 日期欄位右側顯示週幾。
- 日期變更時即時更新顯示。
- 日期無效時顯示 `--`。

### 不包含
- 變更日期欄位本身的輸入格式。
- 影響其他頁面或列表的日期顯示。

## 互動與顯示
- 位置：日期輸入欄位右側。
- 顯示：`週一` ~ `週日`。
- 空值或無效日期：顯示 `--`。

## 技術做法
- 新增工具函式 `getWeekdayLabel(dateStr)`：
  - 輸入 `YYYY-MM-DD`。
  - 回傳 `週一` / `週二`。
  - 無效日期回傳 `--`。
- 在新增與編輯的日期欄位旁加入 `<span>` 來顯示結果。

## 驗證方式（手動）
1) 新增工作紀錄：切換日期，週幾同步更新。
2) 編輯工作紀錄：切換日期，週幾同步更新。
3) 日期清空時，顯示 `--`。

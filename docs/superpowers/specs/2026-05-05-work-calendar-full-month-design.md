# 打工月曆「完整月一屏」設計規格

## 目標
- 手機與桌機皆可在不下拉的情況下看到完整月份月曆。
- 日期格維持正方形外觀，視覺一致。
- 「本月詳細列表」改為可收合，預設收合以節省垂直空間。

## 範圍
- 僅調整打工月曆頁面版面與樣式（`src/app/schedule/work/page.tsx`、`src/app/schedule/work/page.module.css`）。
- 不變更班次資料結構、拖曳/點擊/多選互動邏輯。

## 設計方案（採用）
**方案 A（已選）**
- 維持 7×6 固定格。
- 日期格全面改用 `aspect-ratio: 1`，移除高度依賴，桌機能縮短高度；手機維持方格。
- 「本月詳細列表」改為可收合，預設收合，使用者可手動展開。

## 版面與互動
- **月曆格**
  - `.dayCell` 與 `.emptyCell` 統一以 `aspect-ratio: 1` 控制比例。
  - 桌機移除固定 `min-height` 造成的高度膨脹；保留最小內距以維持可讀性。
- **詳細列表**
  - 預設收合，減少初始高度。
  - 展開/收合按鈕可置於標題列右側，文字使用「展開 / 收合」。
  - 展開後不影響月曆格尺寸；僅影響列表區塊本身高度。

## 樣式指引
- 保持現有玻璃擬態、青綠色系與暗色系一致性。
- 不引入新的 UI 框架或全新視覺風格。

## 驗收條件
- 在桌機與手機（直向）皆能看到整月月曆，不需捲動。
- 每個日期格皆為正方形。
- 「本月詳細列表」預設收合，可手動展開，且互動不影響既有班次功能。

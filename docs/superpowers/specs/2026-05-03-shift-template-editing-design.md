# 班別管理編輯模式設計規格

## 目標
- 讓使用者能在薪資計算頁的班別管理中編輯既有班別。
- 編輯模式沿用既有新增表單，避免新增 UI 元件。

## 範圍
### 包含
- 班別列表新增「編輯」入口。
- 表單切換新增/編輯模式。
- 編輯時支援所有欄位更新與預設衝突處理。

### 不包含
- 新增彈窗或 inline 編輯樣式。
- 批次編輯或歷史版本。

## 互動流程
- 班別列表每列新增「編輯」按鈕。
- 點擊後將班別資料帶入上方表單，進入編輯模式。
- 表單顯示「正在編輯：{班別名稱}」與「取消編輯」。
- 表單主要按鈕文字改為「更新班別」。
- 取消編輯後恢復為新增模式與預設值。

## 資料與規則
- 新增 UI 狀態：`editingTemplateId`。
- 若 `editingTemplateId` 存在，送出時改用 `updateTemplate`。
- 更新時若 `isDefault=true`：先清除同星期其他預設，再設定為預設。
- 更新時若 `isDefault=false`：不主動補新的預設。

## 錯誤處理
- 若無編輯權限，禁止進入編輯並顯示提示。
- 若班別名稱空白，阻止更新並顯示提示。

## 驗證方式（手動）
1) 點「編輯」→ 表單進入編輯模式。
2) 修改欄位並更新 → 列表同步。
3) 取消編輯 → 表單回復新增模式。
4) 預設衝突 → 同星期只保留一個預設。
